How it works

Model. A ratio of two polynomials:

y = p(x)/q(x) = (a₀ + a₁x + … + aₘxᵐ) / (1 + b₁x + … + bₙxⁿ)

Rational functions can level off, have asymptotes and poles, and follow sharp peaks with few parameters, all of which polynomials handle badly.

Least squares (default). For each pair (m, n) the non-linear problem is linearised by Sanathanan–Koerner: repeatedly solve the weighted linear problem min Σ (yᵢq(xᵢ) − p(xᵢ))² / q_prev(xᵢ)², then polish with Levenberg–Marquardt on the true residuals yᵢ − p/q. Pairs whose denominator vanishes inside the data are rejected unless you allow poles. The pair with the lowest AICc (p = m + n + 1 parameters) wins.

AAA. The Adaptive Antoulas–Anderson algorithm writes the rational function in barycentric form

r(x) = Σ wⱼ fⱼ/(x − zⱼ) / Σ wⱼ/(x − zⱼ)

and greedily adds the worst-fitted point as a new support point zⱼ, choosing weights wⱼ as the smallest singular vector of the Loewner matrix. Here the number of support points is chosen by AICc, so noise is not interpolated.

Poles are the roots of q. Real poles inside the range are marked on the chart with orange dashed lines.
