Curve fitting toolkit

Fifteen tools that turn a sheet of y, x data into a best-fit curve, its equation and an exportable image. Each one gauges "best" differently.

Open a tool, press Load sample to see it work, then import your own .xlsx, .csv or pasted data.

Every tool is a single self-contained HTML file. Keep all of them in the same folder so these links work. Reading .xlsx files needs an internet connection the first time (a spreadsheet library loads from a CDN); .csv and pasted data always work offline.
