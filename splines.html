How it works

Idea. Instead of one high-degree polynomial, use many low-degree pieces joined at knots κ₁ < … < κ_K. A cubic spline matches value, slope and curvature at every knot, so it looks like one smooth curve but never develops the edge swings of a degree-50 polynomial.

B-spline basis. The spline is a weighted sum of bump functions, each nonzero over only p + 1 intervals:

ŷ(x) = Σ cⱼ Bⱼ,ₚ(x),   built by the Cox–de Boor recursion

That keeps the least-squares problem banded and well conditioned for any number of knots.

How many knots. More knots always reduce the error, so each knot count is scored with K + p + 1 parameters and the lowest score wins:

AICc = n ln(RSS/n) + 2p + 2p(p+1)/(n−p−1)

Knots are placed at quantiles of x so each piece sees a similar number of points.

Equation. After fitting, each piece is rewritten as an ordinary polynomial in (x − left knot), which is what the equation and table show.
