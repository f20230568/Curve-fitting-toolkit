How the best fit is found

Model. For a set of powers S ⊆ {0, 1, …, 50}, the curve is

ŷ(x) = Σk∈S ak tk,   t = (x − c) / s

where c is the expansion point and s = max|x − c|, so t lies in [−1, 1]. With c = 0 this is exactly y = a₀ + a₁x + … + a₅₀x⁵⁰, and a coefficient that is 0 stays 0 in x.

Least squares. With V the matrix of columns tk, the coefficients minimise the residual sum of squares

RSS = ‖y − Va‖²,   solved by V = QR,   Ra = Qᵀy

QR with Householder reflections and column pivoting is used instead of the normal equations VᵀVa = Vᵀy, which square the conditioning and fail long before degree 50. Powers that are numerically indistinguishable from the others are dropped (coefficient 0).

Gauging "best". RSS always falls as the degree rises, so it cannot pick the degree on its own. Each candidate with p non-zero coefficients and n points is scored, and the lowest score wins:

AICc = n ln(RSS/n) + 2p + 2p(p+1)/(n−p−1) BIC = n ln(RSS/n) + p ln n LOOCV = (1/n) Σ (ei / (1 − hii))²,   hii = Σj Qij² GCV = n · RSS / (n − p)²

Zero coefficients. After the degree is chosen, the term with the smallest |t-statistic|, |ak| / SE(ak), is removed and the model refitted, as long as that lowers the same score. Fit quality is reported as R² = 1 − RSS/TSS and RMSE = √(RSS/n).
